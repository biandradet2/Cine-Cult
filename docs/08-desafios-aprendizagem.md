# Desafios e Aprendizagens

## Desafios:

* **Definição de Requisitos:** Por ser um documento complexo, acabou sendo um desafio para a equipe fazê-lo corretamente.
* **Conexão Estrutura vs. Interface:** Garantir que os protótipos de tela e as histórias de usuário refletissem perfeitamente as regras de negócio e a estrutura de dados (modelo lógico) definidas nas etapas anteriores.
* **Organização:** Conseguir organizar os envolvidos no projeto e separar as responsabilidade entre todos.

## Aprendizagens:

* **Importância da comunicação:** Sem a comunicação constante entre todas as partes o projeto não teria caminhado tão bem quanto foi.
* **Importância do Kanban:** A definição do que seria feito a cada sprint desde a fase inicial de criação do projeto foi essencial para termos a direção exata do projeto.
